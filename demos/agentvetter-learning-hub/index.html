Section 01 · Router

The Tiered Router

What AgentVetter sends to SIE, what it escalates, and why

Tiered Router — Shipped (PR #66 merged · ADR-0016 Accepted) in AgentVetter (formerly tripwire)

Scope decision that held: batch-scoped routing (scan_runs.item_id NOT NULL audited in db/schema.sql), not per-run. Four signals; three pre-computed, one judged by SIE.
Env map: SIE → SIE_ENDPOINT, SIE_API_KEY; chat → ALIBABA_OPENAI_BASE_URL, DASHSCOPE_API_KEY; visuals → DASHSCOPE_HOST, ALIBABA_DASH_SCOPE_API_URL. MODEL_STUDIO_MODEL defaults to qwen3.8-max; SIE_MODEL to gen-4b. Router rows carry scanner_source=tiered_router and are excluded from severity rollups; a prior router row is replaced only after a successful SIE decision (never batch-delete first), so a SIE outage cannot wipe dashboard strips.
What SIE now gives you for free: /v1/score schema is documented (reranking upgrade un-deferred) · /v1/generate + chat with JSON-schema output (typed envelope straight from the model) · X-Trace-ID + timing headers to log per decision.
Design Review — Router vs SIE's Own Patterns
AlignmentASuperlinked's May posts ("Route different AI agent tasks to the right model", "Carve off tasks, not models") and the recap's framing ("use the larger model only where it changes the result") describe exactly this design.
GapBDarwin Router stores low-confidence outcomes as new routing examples (self-updating). The AgentVetter reference set is static (~8–10 hand-authored texts). The request-routing example shows how to verify a classifier at 3,000 cases.
RiskAResolved 5 Oct: SIE_MODEL now defaults to gen-4b (a Cloud alias; see prototypes/sie-studio/models.json), missing keys warn-and-skip rather than fail the scan, and the never-batch-delete rule is in the ADR.

Cautions: Privacy, Upgrades & Model Choice

Three things that bite when wiring a security scanner to a shared inference server.

Privacy — the one that matters most: scanner findings and skill text can be sensitive. Set remote="forbid" on the router's SIE client, log served_by next to the existing timing headers, and keep Model Studio as the only intentionally external hop. The relay default is on, so today a cold start could route router traffic to a partner.
Upgrades: (1) the Helm/NATS/Ingress breaks in 0.9.0 affect people running their own cluster, not hosted callers; (2) the router passes SIE_ENDPOINT + SIE_API_KEY explicitly, but with the 0.9.0 env behaviour and the 0.10.1 hosted fallback, pin the base URL explicitly and re-test before upgrading the SDK; (3) Qwen3Guard-Gen-4B and GLiNER2.5-Decide — both on the integration map — changed defaults in 0.10.1.
Model choice for the three SIE-adjacent jobs: guard (Qwen3Guard, F1 0.827 — best, but Haiku 5.5 is cheaper per check), typed decisions (Decide: far faster, ~8 points less accurate than frontier models — which is why it should gate, not replace, the escalation), redact (SIE composition 0.909 — good enough to sanitise findings before logging, not a compliance control).
Sandbox note
AgentVetter's sandbox already runs on Modal, and a migration guide exists for Modal → SIE. The honest framing from Superlinked's own comparison: Modal wins on bursty compute, SIE wins on sustained inference. Both can be true at once — the sandbox and the router are different workloads.

📝 Hackathon recap — AgentVetter (named "AgentVetter" in the post), as Superlinked wrote it up (18 Aug 2026)
Three scanners, then review. Qwen3.5-4B on SIE reads every result and calls qwen-max when scanners contradict one another, coverage is incomplete or the evidence does not support a clear severity. The dashboard records the full chain including the arbitration note; in one test it returned amber instead of red for a tool-poisoning finding because two of five scanners were unreachable. The post groups AgentVetter (as "AgentVetter") with Darwin Router (Superlinked-track winner, 82.5% routing accuracy, ~60% cost cut) as the two projects that "made the split easiest to see". All nine teams: Darwin Router (Superlinked-track winner), AliBC (Alibaba visual-track winner), Echo (social-media prize), Aida (Mythic; Raspberry Pi Zero 2 W), Sieve (ShieldTech), AgentVetter (TheSandbox; "AgentVetter" in the post) — yours, RentalFinder (Octuple), Venue Visualiser, Yappy.
Status drift to reconcile: your memory says AgentVetter's T1 reads every item via SIE and T2 escalates on four signals (conflicting, unusual_status, semantic_novelty, low_confidence). The gallery guide lists only generate as the primitive used — the /v1/embeddings-based semantic_novelty signal (Encode) isn't credited. Worth a one-line PR to examples/agentvetter/what-sie-does.md.
